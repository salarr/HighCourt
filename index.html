How updates and login work
  1. Keep three files in your GitHub repository: index.html (this app), version.json and user.json.
  2. To release an update, upload the new index.html and raise "version" in version.json.
  3. After every login the app reads version.json. If it is newer, "Update is Available" appears. After updating, "Updated Successfully" appears.
  4. Login checks the username and password hash in user.json. Create each entry with the box below.
